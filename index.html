How I Am Using HTML on This Website

HTML (HyperText Markup Language) provides the structural foundation of this site. Here is how different tags are working behind the scenes right now:

  • <header> & <section>: Used to divide the page into logical, readable content blocks (the banner, About Me, this guide, and the photo gallery).
  • <h1>, <h2>, & <p>: Establish a visual hierarchy for main titles, section headings, and body paragraphs.
  • <ul> & <li>: Structure these bullet points into an unordered list for clean formatting.
  • <img>: Embeds the three images below using the src attribute for the image URL and alt for screen-reader accessibility.
  • <link>: Placed inside the <head> tag to connect this HTML structure to styles.css and custom Google Fonts.
